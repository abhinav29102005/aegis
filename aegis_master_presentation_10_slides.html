Slide 02 • Problems Identified

The Financial Vulnerability of Autonomous Agents

Five fundamental flaws emerge when autonomous LLMs interface with traditional corporate cards.

1. Unbounded Spending Loops

When an agent is trapped in an error correction cycle, recursive API calls or resource allocations can deplete an enterprise balance in minutes.

2. Prompt Injection Financial Exploits

Adversarial inputs or malicious merchant websites can manipulate LLM reasoning into approving unauthorized or exorbitant charges.

3. Concurrency & Double-Spend Races

Independent agent workers operating asynchronously trigger concurrent checkouts that bypass traditional balance checks without serializable transaction isolation.

4. Chargeback & Dispute Vulnerability

Credit card networks require verifiable proof of authorization and fulfillment. Erroneous agent charges lack cryptographic proof, leading to automatic merchant losses.

Slide 07 • Technical Methodology

Core Engineering Invariants & Robustness

Guaranteed mathematical and architectural invariants enforcing financial correctness.

PostgreSQL Advisory Transaction Locks

To eliminate double-spend race conditions across distributed microservices, budget reservation executes inside serializable database locks: SELECT pg_advisory_xact_lock(hashtext(:passport_id)).

Tamper-Evident Merkle Event Ledger

Every event is cryptographically linked: event_hash = SHA-256(prev_hash || canonical_json(event_payload)). Any mutation in historical records immediately breaks trace integrity verification.

Transactional Outbox Pattern

Business state mutations and outbound event delivery are committed in the same ACID transaction, guaranteeing at-least-once delivery with idempotency deduplication.

Prompt Injection Isolation & Fail-Closed Guards

All external data is isolated inside strict XML delimiters: <untrusted_input trust="UNTRUSTED_DATA">. Upstream LLM errors fail-closed to deterministic fallback rules.

Slide 09 • Forensics & Dispute Defense

GhostPay Replay & DisputeOS Contradiction Matrix

How AEGIS defends merchants against fraudulent disputes and unauthorized agent transactions.

GhostPay Counterfactual Simulator

Allows auditors to replay historical agent transactions against hypothetical policy bounds. Rerunning a $750 AWS compute proposal against a $100 policy correctly confirms an invariant violation, enabling proactive risk tuning.

Agent DNA Behavioral Profiling

Builds continuous behavioral profiles tracking spending velocity, merchant categorization, and invocation timeframes. Alerts security teams when an agent exhibits anomalous procurement patterns.

DisputeOS Contradiction Detection

Cross-references buyer claims against immutable server telemetry, quote signatures, and delivery receipts. In the live demo, a claim of "Item Not Received" was contradicted by verified 42.8% token consumption within 14 minutes.

Grounded AI Defense Briefs

Generates structured chargeback defense packets with verified source citations, confidence scores, and mandatory human reviewer approval before network submission.
